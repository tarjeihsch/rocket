# Rocket Engine

- High-performance GPU-driven renderer
- Modern engine architecture with dependency scene graph

## Prerequisites

- **CMake**: Cross-platform build system. [Download CMake](https://cmake.org/download/)

## Building

Built with C++20.
Compilers: MinGW, Clang and GCC on both Linux and Windows.
