# Rocket Engine

A powerful and modular graphics engine designed to propel your game development to new heights!

## Features

- High-performance GPU-driven graphics renderer
- Modern engine architecture with dependency scene graph
- Efficient, lightweight and extremely fast

## Prerequisites

Make sure you have the following prerequisites installed:

- **CMake**: Cross-platform build system. [Download CMake](https://cmake.org/download/)

## Building

Built with C++20 using MinGW, Clang and GCC on both Linux and Windows.
Extensively tested using containerized CI/CD runners on each commit.
